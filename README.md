# Travel Carousel Design Study

An attributed CodePen-derived travel carousel interaction using Swiper. `src/` contains the editable source and `dist/` the static publishing copy.

## Run locally

Open `dist/index.html` in a browser with an internet connection for the Swiper CDN.

A Pen created on CodePen.io. Original URL: [https://codepen.io/icomgroup/pen/JjVgROO](https://codepen.io/icomgroup/pen/JjVgROO).
